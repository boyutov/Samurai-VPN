# Фоновый агент — версия 0.3

Подключённый туннель нужно поддерживать в актуальном состоянии: применять новых и
удалённых участников, переключать участников за NAT на прямой путь и обратно на relay.
Это делает фоновый агент — то же приложение, запущенное с `--agent`, без окна.
Закрытие окна агент не останавливает.

## Как устроено

- Агент работает от имени пользователя, без прав администратора. С туннелем он
  работает через тот же сокет службы, что и окно: samurai-vpnd на Linux, служба
  Samurai VPN на Windows и macOS. Без службы (Linux через pkexec) агент не запускается.
- Привилегированная служба не получает токены сервера и не разбирает его ответы:
  запросы к серверу делает только агент, с правами пользователя.
- Раз в 30 секунд агент запрашивает состав сети и применяет изменения к туннелю
  без переподключения (операция sync). Каждые 5 секунд PathManager проверяет
  прямые соединения (docs/RELAY.md).
- Один агент на папку данных (`agent/agent.lock`). Окно записывает подключённые
  профили в `agent/profiles.json`, агент пишет состояние в `agent/status.json`,
  окно его показывает. В этих файлах нет ключей и токенов; права как у файлов профиля.
- Агент завершается, если в списке нет профилей или ни один туннель не включён
  90 секунд. Перед выходом он возвращает участников с прямого пути на relay.

## Запуск при входе в систему

После «Подключить» окно запускает агент и регистрирует его запуск при входе:

- Linux: `~/.config/autostart/samurai-vpn-agent.desktop`;
- macOS: `~/Library/LaunchAgents/dev.samurai.vpn.agent.plist`;
- Windows: значение `SamuraiVPNAgent` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

Запись только для текущего пользователя. Она удаляется, когда отключён последний
туннель. На Windows туннель WireGuard после перезагрузки поднимается сам, и агент
при входе продолжает его обслуживать. На Linux и macOS после перезагрузки туннеля
нет: агент при входе ждёт 90 секунд и завершается, туннель подключают из окна.

Журнал ошибок агента: `agent/agent.log` в папке данных.

## Что проверяет CI

AgentInstalledTest на Windows и macOS, с установленной службой и без окна: поднимает
туннель, запускает агент отдельным процессом, добавляет и удаляет участника на сервере
и ждёт, что агент применит оба изменения к работающему туннелю; проверяет запись и
удаление автозапуска. BackgroundAgentTest проверяет логику с поддельной службой.

Не проверены: запуск при реальном входе в систему, выход из системы, сон и пробуждение.
